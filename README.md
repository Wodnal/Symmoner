# Summoner — первый прототип

Небольшой тестовый игровой цикл для Roblox: лобби, автоматический раунд и совместный сбор пяти осколков за 90 секунд. Карта создаётся скриптом. Это экспериментальная механика, а не подтверждённая копия геймплея Invokyr. Наград, сохранений, монстров и доната пока нет.

## Запуск без дополнительных инструментов

1. Откройте Roblox Studio и создайте новый пустой Baseplate.
2. В Explorer создайте обычный **Script** в `ServerScriptService` и полностью замените его содержимое кодом из `src/server/Prototype.server.luau`.
3. Создайте **LocalScript** в `StarterPlayer > StarterPlayerScripts` и вставьте код из `src/client/Status.client.luau`.
4. Нажмите Play. Через 15 секунд персонаж попадёт на арену. Подойдите к фиолетовому осколку и используйте предложенную кнопку взаимодействия.
5. Для проверки совместной игры используйте вкладку Test в Studio и запустите локальный сервер с несколькими клиентами.

Альтернатива: подключить папку к Roblox Studio через Rojo, используя `default.project.json`. Rojo и Studio устанавливаются отдельно.

## Известные ограничения

- Подключившийся во время раунда игрок появляется в лобби и участвует со следующего раунда.
- После смерти игрок появляется в лобби и возвращается в игру со следующего раунда.
- Данные, результаты и прогресс не сохраняются.
- Это заготовка для плейтеста, не готовая к публичному выпуску.
