# Подключение Rojo

Rojo 7.7.1 и плагин установлены локально. Два проекта работают отдельно:

| Place | ID | Проект | Адрес Rojo |
|---|---|---|---|
| Лобби | `101772489442671` | `lobby.project.json` | `localhost:34872` |
| Игровая комната | `85770153975326` | `match.project.json` | `localhost:34873` |

Откройте соответствующий place в Roblox Studio. В Plugins откройте Rojo, введите нужный адрес и выберите Connect. До подтверждения синхронизации внимательно проверьте показанные изменения: Rojo может удалять или заменять объекты в управляемых им контейнерах. Сначала сохраните резервную копию и не подключайте адрес игрового места к лобби или наоборот. Если плагин не появился, перезапустите Studio.

Rojo синхронизирует изменения файлов с открытой Studio, но не публикует их автоматически: для каждого place отдельно используйте File → Publish to Roblox. Телепорты проверяются в опубликованном Roblox-клиенте.

Если серверы остановятся, запустите в отдельных окнах PowerShell из `D:\Summoner`:

```powershell
rojo serve lobby.project.json --port 34872
```

```powershell
rojo serve match.project.json --port 34873
```

Если `rojo` не найден, откройте новое окно PowerShell после установки. Серверы рассчитаны на подключение с этого же компьютера. Не открывайте их в интернет.
